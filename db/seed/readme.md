# Versión inicial del catálogo de datos

## Cómo se utiliza

Para utilizar, solamente hay que tener las migraciones iniciales de la base de datos del proyecto, tener una base LIMPIA (sin registros) y ejecutar el comando 'python -m db.seed'.

Para volver a integrar los datos, utilizar 'python -m db.seed --reset' y escribir 'SI' cuando se solicite. Esto borra los registros actuales e integra de nuevo los registros del script.
